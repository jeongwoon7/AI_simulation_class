# PhET-style Electric Field Lab — 수업 배포 패키지

## 폴더 구성

- `phet_style_E_field_example/`
  - 실제 수업용 시뮬레이션 프로젝트
  - `app.py`
  - `physics.py`
  - `pyproject.toml`
  - 기타 VS Code 설정 및 README

- `학생용_가이드/`
  - macOS 설치/실행 가이드
  - Windows 설치/실행 가이드

## 실행 요약

VS Code에서 `phet_style_E_field_example` 폴더를 연 뒤 Terminal에서:

```text
uv sync
uv run python app.py
```

브라우저에서 Terminal에 표시되는 주소를 엽니다.

기본 주소:
`http://127.0.0.1:8050`
